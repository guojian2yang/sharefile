# 文件分享系统
该系统实现了登录、注册、文件上传、文件下载、用户间文件共享和转存、对外图片链接分享，共享下载榜等功能，旨在安全、方便地分享中小文件、图片和视频。

## 功能介绍
- 用户登录注册：用户可以通过注册账号并登录系统，进行文件分享和管理。
- 文件上传下载：用户可以上传自己的文件到系统中，并通过系统提供的下载链接，实现文件的分享和下载。
- 用户间文件共享：用户可以将自己的文件分享给其他注册用户，实现文件的共享和合作。
- 文件转存：用户可以将自己的文件转存到系统中，实现文件的备份和保护。
- 对外图片链接分享：用户可以将自己的图片分享给其他用户，实现图片的分享和交流。
- 共享下载榜：系统会统计用户分享的文件和图片的下载量，展示下载量排名前的文件和图片，方便用户发现热门分享。

## 编译运行
- 编译：
cd sharefile-src
mkdir build
cd build
cmake -DCMAKE_BUILD_TYPE=Debug ..
make -j4
- 运行：
sudo ./bin/sharefile ./tc_http_server.conf
